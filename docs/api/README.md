# API documentation

This directory owns API conventions, endpoint contracts, authentication requirements, validation rules, error models, rate limits, audit behavior and compatibility policy.

Current endpoint evidence also exists in `docs/API_AUDIT.md`, `docs/API_MATURITY.md`, `docs/OPERATIONAL_TRUST_API_AND_PLATFORMIZATION.md` and `lib/api/public-endpoint-inventory.ts`. Future API changes must update the canonical contract here without overstating deployed behavior.
