# Pilot operating boundary

This pilot remains bounded to a local, staged trust-transaction review path.

- No Production deployment.
- No Production migrations or Supabase changes.
- No live external GitHub execution claimed.
- No new authority or trust engine introduced beyond the existing repository patterns.
- All provider and relay behavior is treated as controlled, staged and reviewable.
- The design-partner engine now requires the authenticated actor to be the accountable owner or operator before it proceeds, and otherwise routes the request to review.
