# Hopae target-environment checklist

- [ ] Target URL and build recorded
- [ ] RC6 migration applied
- [ ] Required variable names present; values never printed
- [ ] Hopae enabled for the approved environment
- [ ] Callback registered and HTTPS
- [ ] Session/request retained
- [ ] Provider call completed
- [ ] Signature and timestamp verified
- [ ] Duplicate returned idempotently
- [ ] Normalized evidence and quality retained
- [ ] Authority, policy, decision and enforcement retained
- [ ] Replay, Evidence Graph, Trust Memory and Evidence Pack linked
- [ ] Latency retained
- [ ] Outcome reviewed
- [ ] Execution record status completed

Until every item passes: `Awaiting Credentials` or `Test`, never `Live`.
