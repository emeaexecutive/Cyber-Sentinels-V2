# Release 1.0 RC1

Release candidate date: 2026-07-16.

RC1 turns the existing Trust Fabric into one demonstrable evidence gate. Hopae Connect is primary in approved Test Mode. The canonical Trust Assessment resolves tenant/workflow/policy, verifies signed callbacks, normalizes safe evidence, evaluates evidence quality and authority separately, enforces the result, and atomically preserves Replay, Evidence Graph continuity, append-only Trust Memory, receipt, audit and Evidence Pack references.

Security changes tenant-scope the canonical proof stores and restrict the persistence RPC to service role. The homepage is reduced to six core blocks and the guided demo now shows nine truthful steps and explicit runtime labels.

No new Trust Engine, public route, accuracy claim, raw document store or live-provider claim was introduced. See `docs/SPRINT_13_1_ACCEPTANCE.md` for remaining blockers.
