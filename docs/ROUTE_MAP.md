# Route Map

Last audited: 2026-07-08

This map consolidates all `app/` pages and route handlers without removing capabilities. Visibility describes discoverability, not deletion: internal, admin, deprecated and experimental routes remain available behind the existing auth, admin, noindex and hidden-navigation controls until their content is merged or redirected intentionally.

## Classification Rules

| Class | Meaning |
| --- | --- |
| PUBLIC | Buyer-facing, legal, help, pricing, trust, demo, or company route that can be discoverable. |
| ENTERPRISE | Authenticated workflow, enterprise product, replay, evidence, governance, dashboard, or pilot route. |
| DEVELOPER | Developer documentation, authentication, API key, or integration-owner route. |
| ADMIN | Allowlisted admin, founder operations, repair, review, test, or back-office route. |
| INTERNAL | API/runtime/diagnostic surface or operator route hidden from navigation. |
| DEPRECATED | Valuable but overlapping concept route that should be merged, hidden, or redirected after usage checks. |
