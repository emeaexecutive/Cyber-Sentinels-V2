# Sprint 8.2 Information Architecture

## Outcome

The public site now uses eight primary destinations: Platform, Solutions, Trust, Enterprise, Developers, Pricing, Resources and Login. About and Help are footer-owned. Trust is the authoritative navigation group for trust evidence, memory, replay, governance, provenance, sovereignty and ML validation boundaries.

## Ownership model

- **Platform** explains how Cyber Sentinels works: Trust Engine, Runtime Engine, Authorization Gateway, Replay Engine, Governance Engine, Validation Engine, Evidence Graph and a short link to canonical Trust Memory\u2122.
- **Solutions** explains where it is used: AI agent governance, machine identity trust, regulated workflows, financial services, insurance, executive protection, live session trust and hiring security.
- **Trust** owns the public trust model and canonical links for Trust Posture, Trust Memory\u2122, Replay, Evidence & Audit, Governance, Provenance, Data & AI Sovereignty and ML & Validation Transparency.
- **Enterprise** owns deployment, security, compliance, SSO/SCIM, data residency, pilot, support, architecture and procurement/legal readiness.
- **Developers** owns public integration guidance. Secret and key management remains authenticated.
- **Resources** owns demos, methodology, principles and investor orientation.

## Homepage contract

The homepage answers what Cyber Sentinels is, who it is for, the enterprise problem, the high-level operating model, differentiation and the next action. The canonical flow is:

`Identity -> Authority -> Runtime Risk -> Decision -> Enforcement -> Replay -> Governance -> Trust Memory\u2122`
