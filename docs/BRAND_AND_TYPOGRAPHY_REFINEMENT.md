# Brand and Typography Refinement

## Objective

This pass strengthens the Cyber Sentinels brand through shared typography,
navigation and action styles without redesigning product surfaces. The visual
direction remains calm, high-contrast and operational.

## Wordmark

The global `CYBER SENTINELS` anchor now uses a responsive shared wordmark style:

- restrained cyan-white tone;
- stronger weight;
- controlled uppercase tracking;
- no glow, gradient or decorative effect;
- a dedicated mobile row to prevent crowding.

Because the global navigation is part of the root layout, the refinement applies
consistently to the homepage, authentication, enterprise, Trust Center, replay,
governance, receipts and dashboard surfaces.

## Brand color and actions

Shared primary and secondary action styles establish one quiet hierarchy:

- primary: restrained cyan surface for `Sign in` and `View Demo`;
- secondary: dark cyan border and low-opacity background for enterprise access
  and design-partner actions;
- navigation: neutral zinc border with a subtle cyan hover state.

The shared styles replace inconsistent white, cyan and outline treatments across
the homepage, login, enterprise, investor, design-partner, governance and Trust
Center entry points. They do not introduce gradients, glow or saturated neon.

## Typography hierarchy

Global heading line-height is now consistent while preserving each page’s
existing scale. The oversized Trust Replay heading was aligned with other
protected operational page headings. Existing high-contrast paragraph colors
and readable small-text sizing remain unchanged.

## Navigation

The global header now provides:

- a stronger brand anchor;
- balanced horizontal and vertical gaps;
- a full-width wordmark row on small screens;
- wrapped controls without horizontal overflow;
- dropdowns anchored to their trigger rather than a fixed viewport position;
- explicit primary-navigation labeling;
- direct access to the protected Operational Trust Center.

The enterprise sub-navigation uses the same spacing and restrained secondary
action treatment.

## Accessibility boundaries

- Existing focus-visible outlines remain intact.
- Text contrast is preserved or strengthened.
- Action labels remain plain text and keyboard accessible.
- Dropdown ARIA roles, expanded state, Escape handling and outside-click
  behavior remain unchanged.
- No animation, glow, visual noise or reduced text size was added.

## Scope

This phase changes presentation only. It adds no product feature, database
schema, route, authentication behavior or RLS policy.
