# 30-day GTM execution plan

Period: 20 October–19 November 2026. Owners are roles, not external contractors.
No paid tools, accounts or publication actions are authorized by this plan.

| Period | Owner | Work and measurable completion evidence |
|---|---|---|
| Days 1–3 | Founder + Technical SEO | Review the website content PR's exact changed-file list and checks. Record approval or requested changes. Confirm www canonical, robots, sitemap and internal links in the local report. |
| Days 1–5 | Market Intelligence | Validate six buyer-question hypotheses against dated primary sources; record at least five customer interview questions for founder-led discovery. Do not claim search volume. |
| Days 1–7 | GEO / Analytics | Repeat the three branded query checks on Bing and attempt only legitimately accessible public surfaces. Record exact query, date, locale, result/citation or reason NOT_MEASURED. No sign-ins or scraping. |
| Days 4–10 | Editorial | Present all eight drafts for founder review. Track each as approved, revise or hold; target at least four explicit decisions, not assumed approvals. |
| Days 8–14 | Technical SEO | If the founder authorizes account setup, verify Search Console/Bing ownership through the provider's issued process. Otherwise leave both as NOT VERIFIED. No indexing request before publication approval. |
| Days 8–18 | Founder + Editorial | Select up to two drafts for content-only PR review if claims and internal links are approved. Keep all other drafts unpublished. Record approver, date and exact commit for any approved item. |
| Days 15–21 | Distribution | Submit three post drafts and a directory/community eligibility shortlist for review. Completion means drafts reviewed—not posted or submitted. |
| Days 15–25 | Analytics | If owner exports are available, create a sanitized baseline for impressions, clicks, branded queries, referrals, qualified enquiries and conversion. Otherwise record each as NOT_MEASURED and request access through the approved owner channel. |
| Days 22–30 | GEO + Analytics | Repeat the same query set on accessible surfaces; compare evidence only where access and query conditions match. Count AI citations only when an exact URL is visibly cited. |
| Day 30 | Founder + all roles | Review a one-page outcome report: approvals, published URLs if any, technical issues, external account status, metrics with sources, unresolved blockers and next month's priority. |

## Guardrails and success measures

- 100% of public drafts remain unpublished until explicit founder approval.
- 100% of quantitative claims include a source and reporting period; otherwise
  omit the number.
- 0 agent-originated posts, outreach, account changes, indexing requests or
  incremental external spend without explicit approval.
- Exactly eight initial content drafts are maintained; no high-volume,
  near-duplicate page generation.
- Search Console/Bing ownership is reported as verified only after owner
  confirmation in the provider console.
- Core metrics are tracked weekly only when owner-provided data exists.
  Unavailable data stays NOT_MEASURED; it is never represented as zero.
