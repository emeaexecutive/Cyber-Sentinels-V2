Release: 0.9.4 Focused Enterprise Experience

## Strategy

Archive is a visibility state, not physical deletion. Routes remain in their original Next.js locations so runtime behavior, imports and deep links are preserved. Global navigation and footer do not promote them; middleware protects the internal/experimental families; robots and response headers prevent indexing. Restoration is a configuration and navigation decision after evidence review.

## Retained protected overlaps

These are not archived because they serve live authenticated workflows:

- `/trust-center`: authenticated operational Trust Center; public assurance remains `/trust`.
- `/trust/posture` and `/dashboard/trust-posture`: customer posture data; public explanation remains `/trust#trust-posture`.
- `/trust-replay`, `/replay/[id]` and receipt/report routes: data-backed operational proof; public explanation remains `/verification-replay`.
- `/agents`, `/passports` and their dynamic routes: authenticated records, not marketing duplicates.
- `/enterprise/control-plane` and other protected Enterprise operations: admin workflows, not public Enterprise copy.

## Restoration control

A route can return to public promotion only when it has a unique buyer purpose, a named canonical owner, verified capability boundaries, metadata, navigation placement and an acceptance test. Permanent deletion requires zero imports, zero internal links, zero API dependencies, zero stored/deep-link obligations and an approved migration or redirect window.
