# ML Capability Target Model

Last reviewed: 2026-07-06

| Level | Capability | Evidence required |
| --- | --- | --- |
| 1 | Heuristic only | Explainable deterministic rules and limitations |
| 2 | Provider-ready | Safe adapters, credential checks and normalized contracts |
| 3 | Provider-backed detection | Executed provider inference with health and evidence references |
| 4 | Benchmark validated | Representative labelled datasets with precision, recall, F1 and error analysis |
| 5 | Proprietary model-assisted detection | Versioned trained model plus reproducible evaluation; baseline scoring alone does not qualify |
| 6 | Enterprise validated detection | Deployment-specific validation, monitoring, audit, human review and regulated controls |

Cyber Sentinels is moving toward Levels 3–4 now while laying a Level 5 foundation. The current explainable baseline is not trained ML. Credentials without an implemented, exercised adapter do not establish Level 3, and an empty dataset does not establish Level 4.
