# Release 1 readiness scorecard

Release candidate: 1.1.5
Review date: 2026-07-15

## Scoring rule

This scorecard uses evidence states and observed counts, not estimated percentages. `Implemented` means a code path and evidence contract exist. `Configured`, `Simulated`, `Awaiting Dataset`, `Awaiting Review`, and `Awaiting Credentials` preserve the relevant release boundary. Production readiness requires deployed evidence and cannot be inferred from source code or environment-variable presence.

## Release 1.0 blockers

1. Approved reviewed validation data must meet the calibration gate before accuracy-like claims.
2. At least one provider path needs a successful real health check and reviewed workflow evidence.
3. Deployed RLS, distributed rate limiting, session lifetime, secret rotation, and partner API scopes need production verification.
4. Production-scale performance data and authenticated cross-browser UX evidence are missing.
5. A design-partner workflow must produce a reviewed decision, replay, evidence chain, governance outcome, and Trust Memory update.
