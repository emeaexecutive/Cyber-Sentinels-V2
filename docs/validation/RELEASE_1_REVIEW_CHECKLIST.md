# Release 1 review checklist

- [ ] Correct dataset/version, workflow, signal, provider and ruleset scope
- [ ] Provenance and licence are acceptable
- [ ] No personal, biometric, document or secret content
- [ ] Evidence references resolve to sanitized evidence
- [ ] Expected and actual decisions inspected
- [ ] Ground truth is supportable
- [ ] Uncertainty and disagreement recorded
- [ ] Confidence and rationale recorded
- [ ] Different second reviewer used where dual review applies
- [ ] Approve, dispute or exclude; never force an unusable case
