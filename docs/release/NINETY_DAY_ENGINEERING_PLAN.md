# 90-day engineering plan

## Phase 1 - Days 1-30

- Finalize the truth baseline and public messaging.
- Keep the pricing experience consultation-based and preserve the route.
- Lock the claim regression tests and truth matrix.
- Produce staged evidence for one bounded design-partner transaction.

## Phase 2 - Days 31-60

- Prove one end-to-end provider integration in staging.
- Validate replay, evidence lineage, and policy review with explicit evidence artifacts.
- Complete a single design-partner release package with clear scope, evidence, and limitations.

## Phase 3 - Days 61-90

- Expand only after live proof is available.
- Add a second provider or connector only if the first partner flow is proven.
- Revisit broader public storytelling once the repository has stronger live evidence.

## Guardrails

- Do not expand horizontally beyond the smallest complete design-partner release.
- Do not publicly claim what has not been proven in staging and review.
- Keep Production untouched while the release is being proven.
