# Cross-provider evidence continuity

Evidence retains its original provider, source, subject, observed and received timestamps, classification and digest. A shared chronology never merges provenance. Existing actor/credential/authority references identify the known subject; provider account, session, API/tool, service/model, infrastructure and resource are optional context dimensions.

Declared purpose is the canonical transaction action_purpose. Observed purpose is a later attributed evidence claim. Purpose drift and authority-purpose mismatch are interpretations requiring supporting evidence, never trusted caller booleans or automatic deny reasons. Original purpose is immutable. Missing dimensions remain UNKNOWN, not inferred values.

DECLARED_PURPOSE is an existing fact; OBSERVED_PURPOSE is evidence. CROSS_PROVIDER_ACTIVITY is a relationship/projection. PURPOSE_DRIFT and AUTHORITY_PURPOSE_MISMATCH are evidence-backed interpretations. CAMPAIGN_CORRELATION, IDENTITY_FRAGMENTATION and PROVIDER_VIEW_INCOMPLETE remain future findings/uncertainty concepts, not database enums or intelligence claims.

Provider-local ALLOW remains a provider assertion; it never becomes a canonical/global authorization. Same timing or infrastructure supports correlation only, not a shared human controller, malicious intent or attribution. All correlation is tenant-contained. There is no cross-company surveillance, extraction detection or behavioral decision engine.

Context Replay for Epic 1 orders original facts and later interpretations with source timestamps and receipt timestamps. Clock uncertainty remains visible. Trust Memory records later interpretations separately. Policy affects a future decision only if explicitly configured to require the signal; V1 authorization remains independent.
