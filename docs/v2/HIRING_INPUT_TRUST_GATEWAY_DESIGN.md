# Hiring Input Trust Gateway — design only

Future flow: original candidate document and digest → rendered content → extracted machine content → discrepancy evidence → instruction-like content → explicit policy → REVIEW / DENY / PASS-THROUGH → recruiting agent.

Candidate content may supply candidate information. It has no authority to change system/agent instructions, scoring policy, permissions or evaluation behavior. Preserve original, rendered and extracted references with provenance. Hidden content alone does not establish fraud. Findings require evidence and uncertainty, and any adjudication is appended. No hiring gateway is implemented in V2 Epic 1.
