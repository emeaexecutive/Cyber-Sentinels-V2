# Operational Trust Graph™

## Definition

The Operational Trust Graph™ is the connected operational view of trust over time:

`Identity -> Authority -> Context -> Action -> Evidence -> Replay -> Trust Memory™ -> Continuous Trust`

It is an internal platform concept expressed through existing Entity Identity, Authority Graph, Evidence Graph, Replay and Trust Memory services. It is not a new engine, database or scoring system.

## Boundary with Evidence Graph

- Evidence Graph stores relationships and validates their continuity and integrity.
- Operational Trust Graph™ connects those relationships to chronology, trust-state evolution and the current governed posture.

## Integrity rules

- Every node remains tenant-scoped and attributable.
- Authority must be active, constrained and non-escalating.
- Provider evidence retains source, model, version, latency and limitations.
- Replay and Trust Memory references must remain connected to the decision.
- Missing continuity remains visible and fails closed where execution depends on it.
