# Design Partner Readiness Demo

Duration: 7 minutes. Use only controlled data. Keep the state badge visible at every step.

| Time | Step | State | Demonstrate |
| --- | --- | --- | --- |
| 0:00 | Organization created | Configured | Complete the existing pilot setup and name the accountable administrator |
| 0:35 | Provider configured | Awaiting Credentials | Show purpose, credentials, health and the truthful Test Connection result |
| 1:10 | Trust policy selected | Configured | Show thresholds, escalation, review and evidence requirements |
| 1:45 | Verification initiated | Live | Submit the protected request and evaluate authority |
| 2:25 | Decision | Simulated | Explain why, evidence, authority, policy, confidence and provider participation |
| 3:05 | Replay | Simulated | Follow the replay reference and chronology |
| 3:45 | Evidence Graph | Simulated | Connect identity, authority, evidence, decision and governance |
| 4:25 | Trust Memory™ | Simulated | Show the replay-linked update and no-autonomous-learning boundary |
| 5:10 | Governance | Configured | Assign the human reviewer and next action |
| 6:10 | Enterprise Dashboard | Configured | Close on posture, recent decisions, evidence, Replay, memory, providers, reviews and pending actions |

Say explicitly: Live means the named control ran in this request. Configured does not mean healthy. Simulated proves product behavior, not production accuracy. Awaiting Credentials means no provider call was made.
