# Public Website Walkthrough

Release: 0.9.4 Focused Enterprise Experience
Target duration: under five minutes

## 0:00-0:40 - What Cyber Sentinels is

Open `/`. Read the hero: Cyber Sentinels is Operational Trust Infrastructure for intelligent enterprises. Point to the supporting before/during/after promise and the single primary action, `Request Demo`.

## 0:40-1:15 - Who and what it verifies

Move through the four entity types. Explain that one accountable model covers people, delegated agents, workloads and consequential workflows; hiring is one example, not the platform identity.

## 1:15-2:00 - How authority is enforced

Use the homepage Observe -> Authorize -> Decide -> Prove flow, then open `/platform#authorization-gateway`. Explain that purpose, delegated scope and policy are evaluated outside the acting runtime before execution.

## 2:00-2:40 - How decisions are made

On `/platform`, show Trust Engine, Runtime Trust and Governance. Decisions combine evidence, authority, runtime context and accountable review; they do not claim autonomous truth or perfect certainty.

## 2:40-3:25 - How Replay proves events

Open `/verification-replay`. Show how actor, authority, material change, evidence, reviewer action and outcome form a chronology. Public Replay explains the model; protected replay routes hold customer records.

## 3:25-4:00 - How Trust Memory records evolution

Open `/trust#trust-memory`. Explain the boundary: Replay shows what happened; Trust Memory shows how trust evolved across governed outcomes. It does not claim autonomous learning.

## 4:00-4:35 - How enterprise adoption works

Open `/enterprise`. Show controlled deployment, security, compliance, data residency, pilot programme and named support. The platform sits beside systems of record and can begin with one workflow.

## 4:35-5:00 - Request a pilot

Open `/enterprise/pilot` or select `Request Demo`. Close on the buyer outcome: choose one consequential workflow and make every trust decision explainable.

## Validated buyer journeys

- CISO: `/` -> `/platform` -> `/trust` -> `/security` -> `/enterprise-access?intent=demo`.
- AI/platform leader: `/` -> `/enterprise/agent-governance` -> `/platform#authorization-gateway` -> `/developers` -> `/enterprise/pilot`.
- Risk/compliance: `/` -> `/solutions#regulated-workflows` -> `/trust#evidence-audit` -> `/enterprise#compliance` -> `/enterprise-access`.
- Investor: `/` -> `/platform` -> `/trust#trust-memory` -> `/platform#evidence-graph` -> `/enterprise` -> `/investor` when access is appropriate.

Each journey keeps internal tooling out of public navigation and ends in a clear action.
