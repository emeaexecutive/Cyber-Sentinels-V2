# Enterprise Trust OS Walkthrough

Release: 1.0 Alpha
Target duration: under five minutes

## 1. Enter the workspace

Sign in with a verified enterprise account and open `/dashboard`. Show that public navigation has been replaced by one operational shell with Overview, Operations, Trust, Runtime, Governance, Providers and Administration.

## 2. Explain global context

Point to the single context bar. Open a workspace or Replay record and show how Enterprise, Workflow, Entity, Trust Posture, Authority and Replay context change without adding a second context bar inside the page.

## 3. Use unified search

Press `Ctrl+K`. Search for `agent`, `evidence`, `Replay` and `governance`. Explain that the palette federates existing protected destinations; RLS and route authorization remain authoritative.

## 4. Move through one investigation

Open Operations, select a trust case, move to Runtime for integrity context, then Governance for accountable review. Open Replay to show the retained chronology and Trust Memory relationship.

## 5. Review platform status

Use the persistent status strip. For a verified admin, open Providers and Validation. Call out `Awaiting data`, process-local queue boundaries and provider limitations instead of presenting unsupported fleet health.

## 6. Close in notifications

Open Notification Center. Show that escalations, approvals, evidence requests and review completions live in one center rather than alert cards scattered across every page.

## Demo boundary

Do not claim cross-tenant search, fleet-wide telemetry, live provider health without measured evidence, or universal trust scoring. The alpha unifies existing operational capabilities; it does not add a new trust engine or data platform.
