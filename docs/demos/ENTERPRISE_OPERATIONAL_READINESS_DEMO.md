# Enterprise Operational Readiness Demo

Use `buildEnterpriseOperationalReadinessDemo()` for a controlled product-behavior scenario. Do not present simulated evidence as production traffic.

| Step | Demonstration | Reality state | Operator proof |
| ---: | --- | --- | --- |
| 1 | Human verification | Live | Authenticated accountable-human authority is evaluated |
| 2 | AI agent verification | Configured | Normalized AI-agent identity and bounded delegation |
| 3 | Machine identity verification | Awaiting Credentials | Adapter stays disabled until credential and egress review |
| 4 | Trust Decision | Simulated | Governed controlled-demo decision and next action |
| 5 | Replay | Simulated | Replay reference and chronology |
| 6 | Evidence Graph | Simulated | Linked evidence, authority, decision and execution nodes |
| 7 | Trust Memory™ | Simulated | Append-only operational state with reason and references |
| 8 | Governance review | Configured | Human review remains authoritative and attributable |
| 9 | Enterprise dashboard | Configured | Protected eleven-component readiness workspace |
| 10 | Platform health | Configured | Measured runtime evidence separated from diagnostics and metadata |

## Walkthrough

1. Start with the entity and authority chain, not the score.
2. Show provider state and evidence source before the Trust Decision.
3. Open the explanation object and read the Decision, evidence, authority, policy, confidence, Replay, Trust Memory and next action.
4. Follow Replay into the Evidence Graph and Trust Memory update.
5. Show governance ownership for any review or exception.
6. Finish at `/enterprise/readiness`, calling out Unknown and Awaiting data rather than implying health.

Boundary: the demo proves integration, explainability and fail-closed behavior in a controlled scenario. It is not production provider, scale, accuracy or SLA evidence.
