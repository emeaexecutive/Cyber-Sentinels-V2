# RC3 Canonical Content Ownership

One concept has one authoritative explanatory home. Other surfaces may summarize it and link to that home; they must not reproduce the full narrative or diagram.

| Concept | Canonical owner | Allowed references |
| --- | --- | --- |
| Operational Trust Infrastructure | Homepage `/` | Short category statement elsewhere |
| Enterprise Trust Fabric™ | `/platform#trust-fabric` | Homepage preview and footer link |
| Trust Orchestrator | `/platform#trust-engine` | Mechanism name only elsewhere |
| Living Trust Profile | `/trust#living-trust-profile`; contextual product rendering in authenticated workspace | Summary, demo and footer link |
| Trust DNA™ | `/trust#trust-dna`; contextual product rendering in authenticated workspace | Branded summary and demo |
| Trust Memory™ | `/trust#trust-memory`; protected operational records remain in existing tools | Link and short chronology reference |
| Replay | `/verification-replay`; case records remain protected | Link and evidence reference |
| Evidence Graph | `/trust#evidence-audit`; operational graph tools remain protected/admin | Short relationship summary |
| Authority Lineage | `/platform#authorization-gateway`; contextual authority appears in Living Trust Profile | Bounded status and proof reference |
| Continuous Authorization | `/platform#authorization-gateway`; contextual state appears in Living Trust Profile | Trigger/outcome summary |
| Provider Transparency | `/trust#provider-transparency` | Bounded state and canonical link |
| Validation Transparency | `/trust#ml-validation` | Approved state labels only |
| AI & Data Sovereignty | `/trust/data-sovereignty` | One-sentence boundary and link |
| Governance | `/governance` | Current action/status within protected records |
| Hiring Security | `/enterprise/hiring-security` | One workflow in Solutions; never platform identity |

The public split remains: homepage owns the category story, Platform owns mechanisms, Trust owns assurance and transparency, Solutions owns business outcomes, Enterprise owns deployment/readiness, and Developers owns integration guidance.
