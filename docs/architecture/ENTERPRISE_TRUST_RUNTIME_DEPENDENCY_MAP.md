# Enterprise Trust Runtime Dependency Map

## Canonical graph

Operational Entity
→ Identity
→ Authority
→ Evidence
→ Consequence
→ Decision
→ Execution
→ Outcome
→ Replay
→ Trust Memory
→ Incident
→ Recovery
→ Trust Intelligence

## Notes

- Identity, authority and evidence are adapters to the canonical entity context.
- Trust decisions remain a single evaluator path.
- Replay and Trust Memory derive from transactions and incidents, not from duplicate stores.
- Any capability not connected to the graph is treated as an adapter or explicit compatibility layer.
