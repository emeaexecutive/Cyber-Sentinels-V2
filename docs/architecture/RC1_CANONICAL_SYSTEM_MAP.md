# RC1 canonical system map

This map extends the Epic 29 architecture freeze without changing its frozen contracts. “Canonical” identifies the current owner of meaning and persistence. Adapters and projections may translate or display that state but may not become parallel truth.

## Overlap classification

| Overlap | Classification | RC1 action |
| --- | --- | --- |
| `src/lib/trust-fabric` and `lib/core/trust-fabric.ts` | Canonical composition plus compatibility orchestration facade | Preserve; document ownership; do not add persistence to the facade |
| `src/core/trust/replay`, `lib/core/replay-engine.ts`, `lib/trust-replay`, `src/lib/trust-architecture/replay.ts`, domain replay helpers | Canonical chained replay plus adapters, orchestration and historical compatibility | Preserve; all new references target Replay; no second event store |
| `lib/trust-memory.ts` and `lib/trust-memory/trust-memory.ts` | Compatibility entry point plus canonical domain contract | Preserve; no new emitter in RC1 |
| `src/lib/trust-architecture/evidence-graph.ts` and `lib/evidence-graph/*` | Canonical bounded graph contract plus earlier application projection | Preserve until consumers migrate; no new graph storage |
| `lib/core/decision-intelligence.ts` and `src/lib/trust-decision-intelligence/*` | Compatibility enterprise card projection plus canonical Epic 38 explanation envelope | Keep both read-only; document v1 as canonical for new decision explanation packages |
| `TrustFabricDecisionEnvelope` and `TrustStateDecision` | Composed enterprise decision envelope versus authoritative state transition | Both canonical in their distinct roles; never conflate recommendation, envelope, and applied state |
| `TrustJourneyVisualization` and Replay/Trust Memory timelines | UI projection versus canonical histories | Journey remains derived; it cannot persist or rewrite events |

## Result

One canonical owner is identified for every RC1 capability. The repository contains compatibility layers and domain projections, but the RC1 delta adds no duplicate Trust Fabric, Trust Object, Replay, Trust Memory, Authority Lineage, Evidence Graph, Journey store, or decision ledger.
