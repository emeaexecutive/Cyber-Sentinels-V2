# UX Simplification RC5

## Homepage

The homepage now contains exactly three sections:

1. one outcome-led hero;
2. one operational-trust visual;
3. one identity-versus-operational-trust comparison.

There is one enterprise CTA: `Request Enterprise Demo`. Educational mechanisms remain owned by Platform, proof and transparency by Trust, technical guidance by Resources/Developers, and secondary discovery by the footer.

## Messaging

The primary story is evidence-backed decisions, continuous authorization and replayable operations across humans, AI agents and machine identities. Enterprise Trust Fabric™, AI Agent Governance and Trust Memory™ are used only where they explain the operational outcome.

## Mobile navigation

The mobile menu has a bounded viewport, scroll containment, explicit open/close accessible names, larger touch height and reduced secondary-description density. Desktop dropdown detail remains available.

## Boundary

RC5 changes information hierarchy and clarity. It removes no canonical capability or authenticated workflow.
