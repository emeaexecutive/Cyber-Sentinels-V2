# Platform Glossary

**Establish Trust / Trust Assessment** — Canonical action coordinating identity, authority, provider evidence, evidence quality, decision, enforcement and proof. It is not provider identity verification.

**Trust Decision** — Explainable `allow`, `step_up`, `review`, `escalate`, `block` or `insufficient_evidence` outcome.

**Verification** — Used only for precise provider sessions, identity evidence, signatures and receipts.

**Current Trust Posture** — Latest recorded operational state with limitations and time context; not permanent truth.

**Replay** — Shows what happened and which evidence/decision references were retained.

**Trust Memory™** — Append-only events showing how trust changed and why. It does not imply autonomous learning.

**Evidence Graph** — Tenant-scoped relationships connecting entity, workflow, authority, evidence, decision, enforcement, Replay, governance and posture.

**Provider-neutral evidence** — Safe contract independent of raw provider payload shape.

**Live / Test Mode / Simulated / Awaiting Credentials / Unavailable** — Runtime truth labels. `Live` requires a real successful health check; configuration alone is insufficient.

**Calibration incomplete — insufficient reviewed ground truth.** — Required state when an accuracy-like metric lacks a versioned reviewed dataset and calculation record.
