# RC4 Enterprise Story

## Outcome-led narrative

The public story now leads with enterprise outcomes:

1. Reduce operational uncertainty.
2. Know whether a critical action should proceed and why.
3. Keep consequential work accountable.
4. Understand and replay every critical trust decision.
5. Establish trust continuously as identity, authority and context change.

## Homepage constraints

- Six sections; the maximum remains seven.
- Two total CTAs, both in the hero.
- One primary operational-trust graph.
- No repeated architecture, decision-flow or walkthrough visual.
- Deep architecture remains owned by Platform; proof by Trust; deployment by Enterprise; implementation by Developers.

## Copy boundary

The homepage avoids certainty language, accuracy claims and feature lists presented as outcomes. It does not claim autonomous judgment, universal trust scoring, first-party detection ML, production provider health or regulatory certification.

## Operational demo story

The existing `/demo/trust-execution-flow` route now follows one path only:

`Start → Identity → Authority → Evidence → Decision → Replay → Trust Memory™ → Evidence Pack → Enterprise Dashboard`

The controlled path pauses for accountable review. It does not branch into allow/review/block variants on the buyer-facing page.
