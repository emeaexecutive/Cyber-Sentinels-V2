# Product documentation

This directory owns approved product requirements, product-level decision context, content ownership and acceptance criteria. Product documents describe outcomes and boundaries; architecture decisions belong in `docs/adr/`, and implementation evidence belongs with engineering, testing or release documentation.

## Enterprise Experience architecture

- `enterprise-site-map.md` records public, protected and administrative route ownership.
- `buyer-journey.md` defines the nine stakeholder evaluation journeys.
- `pilot-lifecycle.md` defines discovery through expansion and evidence-bound success criteria.
- `dashboard.md`, `back-office.md` and `governance.md` document current protected operations and gaps.
- `trust-report.md` defines the normative report content/truth contract; `trust-reports.md` inventories current report surfaces and export formats.
- `accessibility.md` and `performance.md` define current evidence, risks and validation requirements.
- `analytics.md` records the dormant current state and the consent-gated future measurement contract.
- `content-guidelines.md` defines approved enterprise terminology, state language and claims boundaries.

Implementation findings and priorities are recorded in `../engineering/enterprise-review.md`.
