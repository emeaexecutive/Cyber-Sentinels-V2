# Testing documentation

## Architecture validation records

- `foundation-validation.md` records the Part 1 engineering foundation gate.
- `platform-architecture-validation.md` records the Part 2 architecture baseline gate.
- `trust-architecture-validation.md` records the Part 3 trust architecture gate.
- `enterprise-experience-architecture-validation.md` records the Part 4 Enterprise Experience documentation gate.

This directory owns the test strategy, quality-gate definitions, environment requirements, manual verification procedures and evidence expectations.

Executable tests remain under `tests/`; deployment and diagnostic harnesses remain under `scripts/`. A document may report only commands and environments that were actually exercised.
