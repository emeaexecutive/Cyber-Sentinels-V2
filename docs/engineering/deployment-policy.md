# Cyber Sentinels Deployment Policy

- Canonical branch: `main`
- Canonical Vercel environment: Production
- Canonical domain: `https://www.cybersentinels.com`
- CS-ENG documentation work does not use a dedicated feature branch.
- Preview deployments are temporary validation environments only.
- Preview URLs must not be presented as the official application.
- Runtime completion requires code, configuration, migrations, tests, deployment, and live verification.
